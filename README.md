# End-to-End Cloud Data Engineering Pipeline

An end-to-end batch data engineering pipeline built using Google Cloud Platform, PySpark, BigQuery, SQL, FastAPI, and Power BI.

## Architecture

CSV / JSON / XML
        ↓
Google Cloud Storage
        ↓
PySpark
        ↓
Data Cleaning & Transformation
        ↓
Data Quality Validation
        ↓
BigQuery
        ↓
SQL Analytics
        ↓
Power BI

## Technologies

- Python
- PySpark
- Google Cloud Storage
- BigQuery
- SQL
- FastAPI
- HTML / CSS / JavaScript
- Power BI
- Git / GitHub
